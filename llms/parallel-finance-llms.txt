# Parallel Finance

> Parallel Finance is a decentralized money-market protocol on the Polkadot ecosystem offering lending, staking, and borrowing. It runs as a Substrate parachain (Parallel mainnet, and the Heiko canary network on Kusama). Integration is via a JSON-RPC node over WebSocket using polkadot.js and Parallel's first-party @parallel-finance TypeScript SDK — there is no REST/OpenAPI surface.

This file was generated by the API Evangelist enrichment pipeline from the repo catalog and verified public sources (npm, GitHub). The hosted documentation (docs.parallel.fi and the parallelfi GitBook) is no longer reachable/served, so links below point only to surfaces confirmed live.

## Endpoints (Substrate/Polkadot JSON-RPC over WebSocket)

- [Parallel mainnet RPC](wss://rpc.parallel.fi): Parallel parachain node.
- [Heiko RPC](wss://heiko-rpc.parallel.fi): Heiko (Kusama) canary network node.
- OnFinality public endpoints: wss://parallel.api.onfinality.io/public-ws and wss://parallel-heiko.api.onfinality.io/public-ws

## Quickstart

```typescript
import { ApiPromise, options, WsProvider, Keyring } from "@parallel-finance/api"

const api = await ApiPromise.create(options({
  provider: new WsProvider("wss://rpc.parallel.fi")
}))

const keyring = new Keyring({ type: "sr25519" })
const signer = keyring.addFromUri("//Alice")
await api.tx.system.remark("hello").signAndSend(signer)
const [route, amount] = await api.rpc.router.getBestRoute("10000000", 100, 1, true)
```
